Self-improving agents

An agent that rewrites itself, and keeps only what works.

Bonsai lets an AI agent improve its own instructions. Every change it tries is a branch. A branch stays only if the agent then scores higher on problems it has never seen. Everything else is cut, and the cuts stay on the record.

How it works

One round, four steps, no human in the loop.

A harness is a small file: the agent's rules, its tools, its turn limit and its model. The model never changes. Everything else is open to revision.

Run

The current best version works through practice problems. Every attempt is traced, pass or fail.

Propose

A second agent reads the failures and writes exactly one change. Whatever it adds, it must remove something of about the same size.

Score

The changed version is tested on held-out problems. The proposer only ever sees that score, never the failures behind it.

Keep or cut

Higher held-out score and no tampering: it becomes the new best. Anything else is cut, and the cut is recorded.

Honest by design

Growth has to be earned.

A self-improving agent will happily improve its score instead of its skill. Bonsai is built so that the only way up is to actually get better.

A kept change grows a branch.
A cut change leaves a stump, and the stump stays.
A pale shoot is a change still being tested.
  • The tests are always the originals. Test files are hashed before the agent starts and restored before grading. A changed hash prunes that version.
  • Answers never enter the agent's folder. Expected results stay hidden from the agent that is being graded.
  • Practice and held-out never mix. A change is judged on held-out problems alone.
  • New problems start a new tree. Scores on different held-out sets cannot be compared, so they are never drawn as one.
